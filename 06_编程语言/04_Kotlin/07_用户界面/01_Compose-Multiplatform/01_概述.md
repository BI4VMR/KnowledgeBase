# 简介
Compose Multiplatform (CMP) 是 JetBrains 维护的开源 UI 框架，旨在将 Android 平台上的 Jetpack Compose 移植到 Desktop、iOS、Web 等多种平台，实现风格统一的用户界面，并尽可能复用代码以降低开发成本。

CMP 工程常见的组织结构如下文代码块所示：

```text
<工程根目录>
├── shared_ui    # Compose UI 代码
├── app_android  # Android 应用程序
├── app_ios      # iOS 应用程序
├── app_desktop  # Desktop 应用程序
└── app_web      # Web 应用程序
```

下文列表对上述工程结构作出了详细的说明：

- `shared_ui` : Compose UI 实现代码，被各平台所引用。
- `app_android` : Android 平台应用，基于 Android 构建工具，具体用法详见 [🧭 Jetpack Compose](../../../../07_平台开发/01_Android/03_用户界面/10_Compose/01_概述.md)
- `app_ios` : iOS 平台应用，需要在 MacOS 环境使用相关工具链编译。
- `app_desktop` : 提供 Windows 、 Linux 、 MacOS 等桌面平台支持，具体用法详见 [🧭 Jetpack Compose](../../../../07_平台开发/01_Android/03_用户界面/10_Compose/01_概述.md)。
- `app_web` : Web 平台应用程序，可生成 JavaScript 或 WebAssembly 浏览器应用。

在上述工程结构中， Compose UI 代码均放置在 `shared_ui` 模块中， `app_desktop` 等模块仅提供对应平台的构建与打包设施，它们不包含复杂的逻辑， 它们均引用并加载 `shared_ui` 模块中的界面实现。

我们可以使用 JetBrains 官方提供的工具快速生成工程模板，不必手动创建目录结构与配置文件： [🔗 Jetpack Compose](https://kmp.jetbrains.com/) 。

Compose Multiplatform 可与 [🧭 Kotlin Multiplatform](../../08_框架集成/01_Kotlin-Multiplatform/01_概述.md) 框架组合使用，以适配多种业务场景：
配合KMP使用，不仅包括Desktop，还支持同一套Compose代码编译为Web和Andori ios应用，实现全平台复用
一种在服务端与客户端共享逻辑代码的框架，二者相结合，即可完全基于 Kotlin 技术栈实现服务端与多平台客户端，达到最大程度的代码复用。

JetBrains 推荐的开发工具是 IntelliJ IDEA 或 Android Studio ，我们可以安装 Kotlin Multiplatform 插件，实现界面组件预览等功能，提高开发体验。
