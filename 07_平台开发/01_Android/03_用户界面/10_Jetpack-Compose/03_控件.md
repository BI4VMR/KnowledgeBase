### 偏移位置

                //相对偏移 这个修改会根据布局方向自动调整水平偏移量(应该是为了阿拉伯语设计的):
                //当布局方向为从左到右时，正x偏移量会将内容向右移动，当布局方向为从右到左时，正x偏移量会将内容向左移动。
                modifier = Modifier.offset(x = 20.dp,y = 25.dp))

            Text(text = "世界", color = Color.Black,
                //绝对偏移 这个修改将不考虑布局方向:正的x偏移总是将内容向右移动
                modifier = Modifier.absoluteOffset(x = 45.dp,y = 20.dp))

## 阴影

Modifier.shadow()（基于 Elevation）是模拟固定光源的，无法直接调整投影角度。要自定义投影的角度和方向，主要有两种常见方案：
1. 使用官方最新的 dropShadow 扩展（推荐）

在最新版本的 Compose Graphics API 中，引入了 Modifier.dropShadow()。它允许通过 DpOffset(x, y) 显式调整偏移量，从而直接改变投影的角度。
Kotlin

Box(
    modifier = Modifier
        .size(100.dp)
        .dropShadow(
            shape = RoundedCornerShape(12.dp),
            shadow = Shadow(
                radius = 8.dp,
                // x 与 y 决定投影的方向和角度（例如右下角 45 度投影）
                offset = DpOffset(x = 6.dp, y = 6.dp),
                color = Color.Black.copy(alpha = 0.25f)
            )
        )
        .background(Color.White, RoundedCornerShape(12.dp))
)
