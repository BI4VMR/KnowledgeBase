# 主题
## 内置主题


MaterialTheme 是 Material 3 库提供的主题组件，当我们将控件放置在 MaterialTheme 块内部时，控件外观将会自动跟随当前主题。



MaterialTheme

内置配色方案、字体、圆角尺寸等定义，这些属性是响应式的，控件关联后，可在主题更新时自动刷新。



主题包括配色方案、字体排版等多种方面，此处以配色方案为例，我们制作适配深色与浅色的两种主题。


第一步，创建配色方案

`Theme.kt` :

kotlin
```
// 配色方案：浅色模式
private val LightColorScheme = lightColorScheme(
    primary = Color.Black
)

// 配色方案：深色模式
private val DarkColorScheme = darkColorScheme(
    // 主要颜色：文本框、按钮等元素的主色调
    primary = Color.White
)
```

`lightColorScheme` 和 `darkColorScheme` 是系统内置的两套配色方案，分别对应浅色与深色主题，我们可以基于它们创建自定义配色方案，修改部分颜色属性，其他属性则保持默认值。

第二步，创建主题组件。

`Theme.kt` :

kotlin
// 自定义主题
@Composable
fun MyTheme(
    // 是否启用深色模式
    darkMode: Boolean,
    content: @Composable () -> Unit
) {
    // 根据深色模式是否启用选择配色方案
    val colorScheme = if (darkMode) DarkColorScheme else LightColorScheme

    MaterialTheme(
        colorScheme = colorScheme,
        content = content
    )
}
```

MyTheme 组件用于封装系统提供的 MaterialTheme ，并根据外部传入的 `darkMode` 参数选择第一步创建的配色方案。

第三步


首先定义枚举表示

`TestUITheme` :

```kotlin
enum class DarkMode {
    // 跟随系统设置
    AUTO,
    // 浅色
    LIGHT,
    // 深色
    DARK;
}
```

然后在界面中使用先前定义的MyTheme，根据用户选择的模式，传入 darkmode。

`TestUITheme` :

```kotlin
        setContent {
            // 深色模式配置项
            var darkModeConfig: DarkMode by remember { mutableStateOf(DarkMode.AUTO) }
            // 是否启用深色模式
            val darkModeState = when (darkModeConfig) {
                DarkMode.AUTO -> isSystemInDarkTheme()

            MyTheme(darkModeState) {
                Surface {
                    // 顶层容器

                            )

## 主题样式

@Composable
fun DefaultTheme(
    darkTheme: Boolean = isSystemDarkTheme(),
    content: @Composable () -> Unit
) {
    MaterialTheme(
        colorScheme = if (darkTheme) darkColorScheme() else lightColorScheme(),
        // typography = ATypography,
        shapes = appShapes,
        content = content
    )
}



val appShapes = Shapes(
    extraSmall = RoundedCornerShape(4.dp),  // text fields, menus

颜色

主色是基础颜色，用于主要组件，例如显眼的按钮和活动状态。

辅色用于界面中不太显眼的组件，例如过滤组件。

第三色用于提供对比鲜明的强调色，中性色用于应用中的背景和 Surface。

## 主题切换

主题在 MaterialTheme 中本质上是切换了不同的配色方案，深色与浅色也是两种配色方案切换，若要支持更多色彩的主题，只需定义更多枚举，并在用户选择后修改MaterialTheme切换即可。

实际上就是向 colorScheme 传入新的参数，可以将主题定义为枚举，作为State，修改state即刷新




## 自定义主题

MaterialTheme 的本质是通过 CompositionLocal 向作用域内注入 `colorScheme.primary` 等属性，主题切换时使得关联组件重组并应用新的颜色等属性，
如果不适用M3设计风格，我们可以自己定义需要的数据结构。

fun ByteArray?.decodeToImageBitmapSafe(context: Context, @DrawableRes default: Int): ImageBitmap {
    val defImg = ImageBitmap.imageResource(context.resources, default)
    // 快速路径：对输入无效的情况直接返回默认值
    if (this == null) return defImg
    if (this.isEmpty()) return defImg

    return BitmapFactory.decodeByteArray(this, 0, this.size)?.asImageBitmap()
        ?: defImg
}
