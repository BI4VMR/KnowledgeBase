# 主题



MaterialTheme 是 Material 3 提供的主题组件，我们会将布局与控件放置在 theme内部，部分控件的属性将会自动跟随当前主题配置。



深色模式，响应式，关联相关变量的组件会自动重组

val isDark = isSystemInDarkTheme()

主题在 MaterialTheme 中本质上是切换了不同的配色方案，深色与浅色也是两种配色方案切换，若要支持更多色彩的主题，只需定义更多枚举，并在用户选择后修改MaterialTheme切换即可。


MaterialTheme

内置配色方案、字体、圆角尺寸等定义，这些属性是响应式的，控件关联后，可在主题更新时自动刷新。


自定义主题

@Composable
fun DefaultTheme(
    darkTheme: Boolean = isSystemDarkTheme(),
    content: @Composable () -> Unit
) {
    MaterialTheme(
        colorScheme = if (darkTheme) darkColorScheme() else lightColorScheme(),
        // typography = ATypography,
        shapes = appShapes,
        content = content
    )
}



val appShapes = Shapes(
    extraSmall = RoundedCornerShape(4.dp),  // text fields, menus
    small = RoundedCornerShape(4.dp),  // chips, snackbars
    medium = RoundedCornerShape(8.dp),  // cards
    large = RoundedCornerShape(8.dp),
    extraLarge = RoundedCornerShape(8.dp),  // AlertDialog
)

颜色

主色是基础颜色，用于主要组件，例如显眼的按钮和活动状态。

辅色用于界面中不太显眼的组件，例如过滤组件。

第三色用于提供对比鲜明的强调色，中性色用于应用中的背景和 Surface。

fun ByteArray?.decodeToImageBitmapSafe(context: Context, @DrawableRes default: Int): ImageBitmap {
    val defImg = ImageBitmap.imageResource(context.resources, default)
    // 快速路径：对输入无效的情况直接返回默认值
    if (this == null) return defImg
    if (this.isEmpty()) return defImg

    return BitmapFactory.decodeByteArray(this, 0, this.size)?.asImageBitmap()
        ?: defImg
}
